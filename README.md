# Random Joke App

A small Android application built with Kotlin to explore REST API integration and local data storage.

## About

This project was developed as a short learning experiment to understand how Android applications communicate with external APIs and process data received from the internet.

The app uses Retrofit to fetch random jokes from an external API and displays them when the user presses a button. Users can also save jokes they like to a local database for later access.

## Features

- Fetch random jokes from an external API
- Display a new joke at the press of a button
- Save favorite jokes to a local database
- Access saved jokes later

## Technologies

- Kotlin
- Android
- Retrofit
- REST API
- Local database

## Project Goals

The main goal of this project was to gain practical experience with API requests, retrieving and displaying remote data, integrating Retrofit into an Android application, and saving selected data locally.

## Project Status

This is a small learning project focused on exploring API integration and data handling in Android development. It was created to experiment with new concepts rather than to build a fully featured application.
